# WikiRace — Claude Code Instructions

Before making any changes to this project, read the following rule files in full. They contain the project overview, design system, and coding conventions that all work must follow:

- `.cursor/rules/project-overview.mdc` — what the app is, core principles, tech stack, key files
- `.cursor/rules/design-system.mdc` — fonts, colors, spacing, UI conventions, what not to do
- `.cursor/rules/code-conventions.mdc` — TypeScript patterns, React patterns, Supabase usage, CSS rules

These are the single source of truth. Do not duplicate or contradict them.

Also check `IDEAS.md` in the root for planned features and context on where the project is headed.
